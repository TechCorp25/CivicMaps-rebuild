NET-NEW / PROPOSED. Design decision: this tier needs a visual signal as unmistakable as Dispatch's navy→teal swap (DS §5), but must not invent a fourth brand colour. Chrome uses a near-black slate (`#0F1729`, darker than `--civic-primary`) with a 2px Patrol Gold rule (badge 1's "Platform" pill and the rail's right border) — gold stays in its permitted lane (accent/signal, not a button fill) while reading as clearly outside any council's navy chrome. Header (badge 1) drops the usual council/branch context entirely — "No council context" is deliberate, this view is above tenant scope. Left rail (badge 2) is icon-only, three destinations matching the planned sequence split: Municipality directory (this file), Domain-pack & sandbox admin (Sequence 14), Cross-council health (Sequence 15).
