# CommandMAPS

Current source-based summary, 20 October 2026. Replaces a committed 415-byte all-NUL file; this is not a recovered historical original.

React/TypeScript/Vite operational web app. The implemented dispatch slice supports scoped request creation, assignment, officer acknowledgement/attendance and administrative closure. F11D supplies the dispatch workspace; merged F11E supplies selection-safe detail/history, confirmed version/status, preserved drafts and uncertain-write reconciliation. Server permissions, operating context, pack entitlements, idempotency and optimistic concurrency remain authoritative. ADMIN identity alone does not authorise operational access.

Run from the repository root using the [local build guide](../../docs/development/local-build.md). Root build/check scripts cover this app. Browser checks require the documented synthetic database/harness. The governance queue contract loads every authorised request page; the first page carries scoped counts and later cursor pages omit them.

Use the current [_ds guidance](../../_ds/README.md), canonical tokens and annotations. Header identity is department/role. Demo design states do not create server capabilities.

Next work: [F11 build plan](../../docs/plans/F11-next-phase-build-plan.md), connecting newly provisioned council staff through explicit authorised administration. Native mobile, full lifecycle, evidence/infringements, offline and live operational acceptance are not implemented by this app summary.
