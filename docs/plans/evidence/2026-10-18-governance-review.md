## Outcome

All 65 original finding IDs have been reassessed against current main. Two supplied security paths remain statically confirmed: **F-009 shared-capacity exhaustion through authorised resource-status work** and **F-029 stored malformed audit reasons reaching a reader's React render**. That group includes valid functional defects and production architecture gaps; it must not be described as 56 fixes or false positives.

Production council administration, broker isolation, record retention, incident handling and cloud/identity decisions need a separate governed implementation programme.

Existing restricted application roles and council isolation checks remain meaningful controls within the synthetic development model.

## Priority corrective work

### F-002: complete operational discovery

Current [request list](../../../services/api/app.mjs) orders by descending number and limits to 100 before the client [filters and counts](../../../apps/commandmaps/src/main.tsx). Older active work can disappear behind newer closed work; records are not deleted and known-ID access remains scoped. Define server-side filters, stable pagination and complete authorised counts. Acceptance must include more than 100 mixed-status requests, older active assignments, council/branch isolation and pagination under concurrent updates. Removing the limit without a bounded query is not sufficient.

### F-011: idle-pool reliability

[database.mjs](../../../services/api/database.mjs) creates a shared max-10 pg.Pool with no pool `error` listener. API and workers import it. An unhandled idle-client error can terminate a process; systemd restart does not preserve in-flight work. Add non-secret error classification and appropriate readiness/recovery handling. Disposable failure cases must distinguish pool recovery from failed transactions and preserve idempotency; never blindly replay writes.

### F-009: authorised resource-status work occupies shared control capacity

Security queue rank **confirmed 1**. An authenticated non-ADMIN needs a valid route/context and `resources.read` entitlement. [app.mjs:352](../../../services/api/app.mjs) enters a control transaction, then [withMunicipalityResource](../../../services/api/data-resources.mjs) validates ownership, describes/reads a resource secret, opens a separate verified-TLS database connection and acquires STS storage credentials even though the status callback only reads database readiness. The shared control client remains held throughout. Per-call timeouts exist, but endpoint admission/concurrency limits and isolation from slow provider work are absent.

Repeated permitted work can occupy shared capacity and affect other callers. Exact outage threshold/latency is unmeasured. This is availability amplification through authorised work, not credential or tenant-isolation bypass. A repair must remove unused storage acquisition, bound expensive work and retain an independent control capacity/deadline budget while preserving revocation, entitlement and ownership ordering.

`$fix-finding` handoff: current main `0aba5e0`; entry `app.mjs:352–374`, adapter `data-resources.mjs:347–361,405–435`, pool `database.mjs:4`. Define admission/backpressure and consistency strategy; verify disposable delayed-provider concurrent work alongside unrelated API requests, disabled resources, revoked contexts and ownership conflicts. No live saturation test is authorised by this handoff.

### F-029: malformed audit reason reaches another reader

Security queue rank **confirmed 2**. A dispatcher assigning or an assigned officer acknowledging/attending, with enabled capability, valid scope/version/CSRF/idempotency, can supply a non-string reason. Current [action validation](../../../services/api/app.mjs) checks reason type only for `close`, stores the value for other permitted actions, and [CommandMAPS](../../../apps/commandmaps/src/main.tsx) renders `event.details.reason` directly as a React child. A plain object reaches an invalid-child render path for another authorised reader. This is durable audit-view availability/integrity, not demonstrated script injection.

`$fix-finding` handoff: current main `0aba5e0`; validation `app.mjs:455–473`, audit persistence `503–515`, rendering `main.tsx:650–657`. Enforce action-specific bounded string/null semantics before mutation and tolerate malformed historical values in rendering without rewriting immutable history. Verify disposable type-rejection and legacy-history browser cases; preserve D03 retained review, CSRF, versions, receipts and council isolation. No browser exploit reproduction was performed here.
