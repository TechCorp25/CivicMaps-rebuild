## Implemented behaviour

Migration012 and scoped transitions create a designated ADMIN only through a hashed,24-hour, single-use token tied to one municipality and immutable context version. Operator issuance requires recipient verification and explicit context; reissue revokes old links and receipt replay never returns the bearer secret. Atomic redemption and chosen credential setup permit one concurrent success. Failed, expired, reused or wrong-context redemption records non-secret audit.

ADMIN has only own profile/session and explicit-context discovery. API role checks and restrictive database policies deny operational data and personnel; Platform identity stays separate. Disable revokes sessions and links, including a login that waited behind the committed disable. Registration now creates a pending designation without returning a temporary password. Historical pending hashes/receipts remain unchanged. Bootstrap does not demote activated/disabled councils or replace data/identities/grants/ownership.

Operator and council UI cover issue/reissue, explicit context, verification, expiry/used states, lost-response recovery, password setup, own profile and disable. Address-bar bearer fragments are removed; no token enters local/session storage or server URL logs. [Runbook](../../development/first-admin-activation.md) records API, concurrency, release and recovery limits.
