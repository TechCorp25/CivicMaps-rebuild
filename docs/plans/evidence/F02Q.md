## Gotchas and prevention

ESLint 9.39.3 emitted a deprecation warning. An attempted ESLint 10 upgrade with Hooks 7.0.1 failed peer resolution. Inspect current peer ranges and install mutually compatible pinned versions; do not use force/legacy-peer-deps. Hooks 7.1.1 and typescript-eslint 8.71.2 accept ESLint 10.

Playwright page.evaluate runs in the browser although its containing script is Node code; declare only the browser globals used by those callbacks. Do not grant browser globals to all server files.

A prior full-check request was not executed when automatic approval review hit a usage limit. The authorised run succeeded after resumption; do not describe unexecuted commands as failed tests or bypass review.
