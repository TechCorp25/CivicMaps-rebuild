Author: Codex (agent), 13 October 2026.

Branch: codex/civicmaps-f02-platform-acceptance.

## Change

Added eight platform API acceptance cases and a self-contained Chromium workflow that creates/removes its own disposable database and starts ephemeral API/Vite servers. CI now installs Chromium, runs the browser acceptance script and retains screenshots as an artefact. The root suite includes foundation and platform API tests.

Browser acceptance found and fixed two existing contract defects: changing pages with the same municipality ID cleared detail but did not reload it, disabling pack switches; an absolutely positioned accessible table label extended the narrow-screen document beyond its scroll container. Detail loading now follows page changes, and the table container establishes the label's containing block. These restore intended behaviour without adding a new feature.
